## 🧠 Overview

GPU-Z is a lightweight Windows utility focused on graphics hardware information. It can identify the installed graphics adapter and display detailed information about the GPU, video memory, clocks, drivers, supported technologies, and other hardware parameters. :contentReference[oaicite:0]{index=0}

The application also provides sensor readings such as GPU temperature, clock frequencies, fan speed, GPU load, and other values depending on the graphics adapter. :contentReference[oaicite:1]{index=1}

## 🚀 Key Features

| Feature | Description |
|---------|-------------|
| 🎮 GPU Identification | Displays the graphics card model, GPU name, revision and vendor information |
| 💾 Memory Details | Shows memory type, capacity, speed and bus width |
| 📊 GPU Sensors | Monitors temperature, clocks, fan speed and GPU load |
| ⚙️ Clock Information | Displays default, current and boost clock values when available |
| 🖥️ Display Information | Provides adapter and display-related information |
| 🔧 Hardware Details | Shows BIOS, device ID, bus interface and supported technologies |
| 🧪 GPU Load Test | Includes a test for checking PCI-Express configuration |
| 📋 Validation | Allows hardware information to be validated and shared |
| 💿 BIOS Backup | Provides an option to create a backup of the graphics card BIOS |
| 🪶 Lightweight | Designed as a compact utility for Windows systems |

## 💻 System Requirements

- **Operating System:** Windows 10 / Windows 11
- **Architecture:** 32-bit and 64-bit
- **Processor:** Compatible x86/x64 Windows PC
- **Graphics:** NVIDIA, AMD/ATI or Intel graphics device
- **Storage:** Small amount of free disk space

GPU-Z supports graphics hardware from NVIDIA, AMD/ATI and Intel, with both portable and installer-based usage available. :contentReference[oaicite:2]{index=2}

## Additional Information for Windows Users

GPU-Z can be useful when checking the exact model and specifications of a graphics card, reviewing memory configuration, monitoring sensor readings, or collecting GPU information while troubleshooting graphics-related issues.

The Sensors section can display live hardware readings, while the application can also log sensor information for later review. NVIDIA's support documentation specifically references GPU-Z for collecting GPU sensor logs when investigating graphics performance issues. :contentReference[oaicite:3]{index=3}

GPU-Z is designed specifically around graphics hardware, making it useful for checking GPU specifications without relying solely on Windows' basic device information.
